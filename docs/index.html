Visão geral

StackOS Genesis C3 é uma distribuição Linux independente desenvolvida pelo projeto StackOS. A antiga linha baseada em Ubuntu pertence ao histórico do projeto. A linha C3 utiliza um processo de construção nativo a partir de fontes e componentes upstream.

Identidade técnica

Não descreva C3 como “baseada no Ubuntu”. O projeto mantém processo de build, integrações, pacotes e repositório próprios.

O uso de APT, pacotes DEB, GNOME, systemd e bibliotecas upstream não significa, por si só, que a distribuição seja derivada do Ubuntu. A origem e a proveniência das dependências devem ser documentadas individualmente.

Arquitetura e componentes

  • Base do sistema: linha C3 nativa.
  • Kernel da RC3: Linux 7.2.13.
  • Desktop da RC3: GNOME 50.6.
  • Arquitetura: amd64.
  • Aplicativos: pacotes e integrações StackOS junto a componentes upstream.
  • Distribuição de software: repositório C3 com metadados e pacotes assinados.
Transparência

Não se afirma que todas as bibliotecas foram escritas pelo StackOS. A auditoria de dependências deve distinguir fontes upstream, componentes compilados no ambiente C3 e eventuais binários legados.

Instalação e mídia

A RC3 é candidata a lançamento. Faça backup antes de instalar e teste primeiro o boot Live. Confirme cuidadosamente o disco de destino antes de qualquer operação destrutiva.

sha256sum StackOS-C3-live-v10.9-RC3.iso

A bateria completa de instalação e recuperação não foi repetida para esta RC3; a validação em PC físico permanece pendente conforme o manifesto.

Atualizações C3 assinadas

A ISO atual contém um fluxo de ativação de atualizações assinadas. As instruções registradas no README do projeto são:

curl -fLO https://stackoslinux-dev.github.io/repo/c3/enable-c3-updates.py
curl -fLO https://stackoslinux-dev.github.io/repo/c3/enable-c3-updates.py.asc
gpgv --keyring /usr/share/keyrings/stackos-archive-keyring.gpg enable-c3-updates.py.asc enable-c3-updates.py
sudo python3 enable-c3-updates.py
sudo /usr/lib/stackos/stackos-updater-helper install

Não desative a verificação de assinaturas nem use fontes APT marcadas como trusted=yes. Consulte as instruções oficiais da versão instalada.

Open Invention Network

A correspondência de maio e junho de 2026 registra o convite da Open Invention Network à StackOS. Em 28 de junho de 2026, o representante da OIN respondeu “Welcome to the Open Invention Network”. O e-mail confirma a recepção do processo de adesão.

A OIN trabalha para proteger Linux e software open source contra agressão relacionada a patentes. A adesão deve ser descrita como participação na comunidade OIN; não é certificação da distribuição, auditoria de segurança ou endosso técnico.
