Documentacao oficial do StackOS Genesis — distribuicao Linux baseada no Ubuntu 26.04 LTS.

Use o menu lateral para navegar.

O que e o StackOS Genesis?

  • Sistema live com GNOME 50.1
  • Instalador GTK proprio com 3 modos
  • Repositorio APT online
  • Tema StackOS-Dark exclusivo
  • Ferramentas: Store, Drivers, Fastfetch

Criar Pendrive Bootavel

No Linux

# Identificar pendrive
lsblk
# Gravar ISO
sudo dd if=stackos-1.0-amd64.iso of=/dev/sdb bs=4M status=progress oflag=sync

Atencao: substitua /dev/sdb pelo seu dispositivo. Todos os dados serao apagados.

No Windows

Use o Rufus (rufus.ie) ou Balena Etcher. Selecione a ISO e grave no pendrive.

Usando o Instalador

Modos de instalacao

  • Apagar disco inteiro — Apaga tudo e instala o StackOS.
  • Dual boot — Instala ao lado do sistema existente.
  • Particionamento manual — Abre o GParted.

O modo apagar disco remove todos os dados permanentemente.

Pos-Instalacao

sudo apt update && sudo apt upgrade -y
sudo apt install stackos-store stackos-drivers stackos-themes

Repositorio StackOS

echo "deb [trusted=yes] https://stackoslinux-dev.github.io/repo genesis main" | \
  sudo tee /etc/apt/sources.list.d/stackos.list
sudo apt update

Solucao de Problemas

WiFi nao funciona

sudo rfkill unblock all
sudo systemctl restart NetworkManager

Boot nao aparece no UEFI

sudo grub-install --target=x86_64-efi --efi-directory=/boot/efi --bootloader-id=StackOS
sudo update-grub

Tela preta apos boot

No menu GRUB, selecione StackOS Genesis (modo seguro).
